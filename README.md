# WebGIS de séries ambientais

Projeto de visualização e consulta geoespacial de séries ambientais, desenvolvido com uma API em Python e uma interface web baseada em JavaScript, HTML e CSS. O código reúne módulos para análise de indicadores, séries temporais, consultas por coordenadas e representação cartográfica.

## Escopo deste repositório
Esta cópia contém código-fonte e documentação. Arquivos de dados, pontos geográficos, planilhas de trabalho, caches, exportações e ambientes locais foram excluídos. Os dados de entrada têm origem e condições de redistribuição próprias; não estão incluídos neste repositório.

Para executar a aplicação, será necessário configurar localmente as fontes de dados compatíveis com os módulos em `app.py`. A estrutura de dados original não faz parte deste repositório. Este repositório contém código, não uma aplicação hospedada; a execução exige configuração local.

## Estrutura
- `app.py` — API e rotas do WebGIS.
- `mapa.js`, `index.html`, `estilo.css` — interface e visualização do mapa.
- Módulos Python — processamento de séries, indicadores, escalas, exportação e consultas ambientais.
- Arquivos `test_*` — testes de partes da aplicação; a execução pode depender de dados locais não incluídos.
- Arquivos Markdown — documentação dos módulos e funcionalidades.

## Privacidade e dados
Coordenadas, nomes de pontos, dados brutos e saídas geradas permanecem fora deste repositório.
